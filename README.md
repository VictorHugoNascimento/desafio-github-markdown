## Linguagem markdown

A linguagem markdown é uma linguagem de marcação simplificada usada para editar conteudos principalmente no GitHub.
Sua sintaxe é bem fácil e intuitiva, para deixar um texto em italico nos usamos um unico asterisco no começo e no fim da paravra para deixa-la em italico, por exemplo, *markdown*.
para deixarmos a palavra em negrito, nos usamos dois asteriscos, por exemplo, **negrito**.

## Sobre o desafio

O desafio é para criarmos um repositorio publico e seguirmos algumas etapas:

- Adicionar um colaborador
- Abrir um Pull Request
- Abrir uma Issue
- Editar nosso arquivo README.md utilizando a linguagem de marcaçao markdown
